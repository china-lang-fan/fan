# 凡语言语法方案

> 版本：草案 v0.1
> 说明：本文件记录凡语言的语法方案。方案确定后再进入实现阶段。

## 一、总体设计原则

1. 中文优先：关键字、内建函数、错误提示全中文。
2. 简洁一致：一种做法只提供一种主写法，部分符号型 token 允许「符号 / 中文描述」双写。
3. 动态类型：变量默认动态类型；显式声明类型后运行时强制检查。
4. 表达式驱动：函数体、条件分支均为块。
5. 便于解释执行：语法可通过 Pratt Parser 单遍解析，避免歧义。

## 二、双写规则（符号 ↔ 中文描述）

凡语言使用中文关键字，但以下运算/赋值 token 同时支持「符号」和「中文描述」两种等价写法，用户可择一使用，两者语义完全相同。

| 类别 | 符号 | 中文描述 |
| --- | --- | --- |
| 赋值 | `=` | `为` |
| 复合赋值 | `+= -= *= /=` | `加等于 减等于 乘等于 除等于` |
| 自增/自减 | `++ --` | `自增 自减` |
| 相等 | `==` | `等于` |
| 不等 | `!=` | `不等于` |
| 小于 | `<` | `小于` |
| 小于等于 | `<=` | `小于等于` |
| 大于 | `>` | `大于` |
| 大于等于 | `>=` | `大于等于` |
| 加 | `+` | `加` |
| 减 | `-` | `减` |
| 乘 | `*` | `乘` |
| 除 | `/` | `除` |
| 取余 | `%` | `取余` |
| 逻辑与 | `&&` | `且` |
| 逻辑或 | `\|\|` | `或` |
| 逻辑非 | `!` | `非` |

## 三、变量与常量声明

### 3.1 通式

```
[定义] [变量|常量] [类型] 名字 (为|=) 值
```

### 3.2 规则

1. **必须赋初值**：变量、常量声明都必须给初值。
2. **常量关键字不可省略**：`常量` 必须显式写出。
3. **常量不可再赋值**：常量再次赋值报错。
4. **可省略部分**：`定义`、`变量`、`类型` 可省略；省略 `变量` 默认即变量。
5. **关键字顺序固定**：`定义 → 变量|常量 → 类型 → 名字 → 为|= → 值`，顺序不可打乱。
6. **赋值符双写**：`为` 与 `=` 完全等价。
7. **类型强制检查**：声明类型后，初始化与后续赋值都强制运行时类型检查,不匹配则报错。
8. **变量可再赋值**：受类型约束。

### 3.3 合法示例

```凡
# 声明（必须有初值）
名字 为 "小明"
名字 = "小明"
定义 名字 为 "小明"
变量 名字 = "小明"
定义 变量 名字 为 "小明"
变量 整数 年龄 = 18
定义 常量 小数 圆周率 为 3.14
常量 圆周率 = 3.14

# 后续赋值
年龄 = 20
年龄 为 21
```

### 3.4 非法示例

```凡
变量 名字                 # 错误：必须赋初值
定义 整数 年龄            # 错误：必须赋初值
定义 圆周率 为 3.14        # 错误：想声明常量却缺 常量
常量 圆周率               # 错误：缺初值
变量 整数 年龄 = "十八"    # 错误：类型不匹配
圆周率 = 3.15              # 错误：常量不可再赋值
```

## 四、类型系统（初版）

内置类型名（中文）：

| 类型 | 说明 | 字面量示例 |
| --- | --- | --- |
| 整数 | 有符号整数 | `0`、`42`、`-7` |
| 小数 | 浮点数 | `3.14`、`-0.5` |
| 字符串 | UTF-8 文本 | `"你好"` |
| 布尔 | 真/假 | `真`、`假` |
| 数组 | 有序元素集合 | `[1, 2, "三"]` |
| 字典 | 键值对集合 | `{"名": "小明", "岁": 18}` |
| 函数 | 可调用对象 | `函数(数) 返回 数 乘 数 结束` |
| 空 | 空值 | `空` |

## 五、注释

### 5.1 规则

1. 只支持**单行注释**，从起始标记开始到本行行尾结束，词法阶段丢弃。
2. 起始标记二选一，语义完全等价：
   - 符号形式：`#`
   - 中文形式：`注释`
3. `#` 后不做任何要求，一出现即吃到行尾（可紧跟内容、可有空格、可为空注释）。
4. `注释` 是保留字，标识符不可与其重名。`注释` 后必须紧跟以下之一才被识别为注释，否则视为标识符：
   - 空白（空格 / Tab）
   - 冒号（半角 `:` 或全角 `：`），冒号后可有可无空白
   - 行尾（构成空注释）
5. 字符串字面量内部的 `#` / `注释` 视为普通字符，不触发注释。

### 5.2 合法示例

```凡
# 单行注释
#单行注释
#
注释 单行注释
注释: 单行注释
注释:单行注释
注释： 单行注释
注释：单行注释
注释                              # 空注释

变量 年龄 = 18   # 行尾注释
变量 名字 = "小明"   注释: 行尾中文注释
变量 提示 = "价格#100"            # 字符串内 # 是普通字符
变量 备注 = "含 注释 字样"         # 字符串内 注释 是普通字符
```

### 5.3 非法示例

```凡
注释这是注释      # 错误：注释 后既不是空白/冒号也不是行尾，视为标识符
注释abc           # 错误：同上
```

## 六、语句结束

1. 一行一条语句，语句**以换行结束**。
2. **不支持** `;` 分隔多语句。
3. 空行忽略；行首/行尾空白忽略。
4. 括号 `(` / `[` / `{` 内允许折行；未闭合前不视为语句结束。

## 七、运算与类型语义

### 7.1 算术

- 运算符：`+ - * / %`，对应中文 `加 减 乘 除 取余`。
- **数值自动提升**：整数与小数混算自动提升为小数；两端都是整数时结果为整数。
- **除法 `/`**：整/整 = 整数（截断向零）；任一端为小数则结果为小数。
- **取余 `%`**：**仅允许整数 % 整数**，其他类型报错。
- **除零 / 模零**：运行时报错「除数不能为零」。
- **字符串拼接**：`字符串 + 字符串`（中文 `加`）返回拼接后的新字符串；字符串与其他类型相加会报错，不做隐式转换。

### 7.2 比较

- 运算符：`== != < <= > >=`，对应中文 `等于 不等于 小于 小于等于 大于 大于等于`。
- **同类型才可比较**（整数、小数之间自动提升后比较）。
- **跨其他类型比较**（含 `==` / `!=`）一律**报错**，不做隐式转换。
- 结果为布尔。

### 7.3 逻辑

- 运算符：`&& || !`，对应中文 `且 或 非`。
- **操作数必须为布尔**，其他类型报错，不做 truthy 转换。
- **短路求值**：`且` 左侧假则不求右侧；`或` 左侧真则不求右侧。

### 7.4 三元表达式

- 语法：`条件 ? 真值 : 假值`。
- 条件必须是布尔；条件为真计算并返回真值，否则计算并返回假值。
- 支持全角 `？`、`：`。
- 未命中分支不计算。

### 7.5 优先级（低 → 高）

```
三元 ? :
或
且
非
== != < <= > >=
+ -
* / %
一元 -
括号 ()
```

### 7.6 声明与作用域

- 同一作用域**重复声明**报错：`变量 X 已声明`。
- **未声明就赋值**报错：`变量 X 未声明`。
- 声明了类型的变量，后续赋值必须匹配类型，否则报错。
- 常量再赋值报错。

## 八、条件语句

### 8.1 形态

```凡
如果 条件 那么
    语句…
否则如果 条件 那么
    语句…
否则
    语句…
结束
```

### 8.2 规则

1. `如果 条件 那么` 开始，`结束` 收尾，整条分支链**共用一个 `结束`**。
2. `那么` **必须写出**，作为条件表达式的终止标记。
3. `否则如果 条件 那么` 可出现 0 到多次。
4. `否则` 最多出现一次，且必须是最后一个分支；`否则` 后**不跟** `那么`。
5. `否则如果` 也可写成分开的两个词 `否则 如果`，语义相同。
6. **条件必须是布尔**，其他类型报错，不做 truthy 转换。
7. 每个分支的块**引入新作用域**：块内声明的变量出块即失效；块内可读写外层已声明的变量。
8. 支持嵌套，内层 `如果` 自带自己的 `结束`。

### 8.3 合法示例

```凡
如果 分数 大于等于 60 那么
    等级 = "及格"
结束

如果 分数 大于等于 90 那么
    等级 = "优"
否则如果 分数 大于等于 60 那么
    等级 = "及格"
否则
    等级 = "不及格"
结束

注释 嵌套
如果 甲 大于 0 那么
    如果 乙 大于 0 那么
        象限 = 1
    结束
结束
```

### 8.4 非法示例

```凡
如果 分数 大于等于 60
    等级 = "及格"
结束
注释 错误：缺少 那么

如果 1 那么
结束
注释 错误：条件必须是布尔

如果 甲 那么
    ...
否则 那么
    ...
结束
注释 错误：否则 后不跟 那么

如果 甲 那么
    ...
注释 错误：缺少 结束
```

### 8.5 判断语句

```凡
判断 状态码
    为 200
        打印("成功")
    为 301、302
        打印("重定向")
    当 状态码 >= 500
        打印("服务器错误")
    其他
        打印("其他情况")
结束
```

规则：
1. `判断 [表达式]` 开始，`结束` 收尾。
2. `为 值1、值2` 是值匹配分支；多个值用逗号或顿号分隔。
3. `当 条件` 是条件匹配分支；条件必须是布尔。
4. `其他` 是默认分支，最多一个且必须在最后。
5. 命中第一个匹配分支后立即结束整个判断，默认不贯穿。
6. `判断` 后不写表达式时，只能使用 `当` 和 `其他`。
7. 跨类型值匹配视为不匹配，不报错。

## 九、数组

### 9.1 字面量

```凡
变量 空数组 = []
变量 数字 = [1, 2, 3]
变量 混合 = [1, "二", 真, 3.14]
变量 嵌套 = [[1, 2], [3, 4]]
变量 尾随 = [1, 2, 3,]
```

- 类型名：`数组`
- 元素允许任意类型混合，不做元素类型约束（不支持「整数数组」这类泛型标注）
- 允许尾随逗号
- `[` 未闭合时不视为语句结束，允许跨行书写：

```凡
变量 名单 = [
    "小明",
    "小红",
]
```

### 9.2 类型声明

```凡
变量 数组 名单 = ["小明", "小红"]
定义 常量 数组 固定 为 [1, 2, 3]
```

声明 `数组` 类型后，初始化与后续赋值都必须是数组，否则报错。

### 9.3 索引访问

```凡
变量 数字 = [10, 20, 30]
数字[0]        注释 10
数字[2]        注释 30
```

- **下标从 0 开始**
- **越界报错**：`数组下标越界：长度 3，下标 5`
- **不支持负数下标**，负数即越界报错
- 下标**必须是整数**，小数/字符串等报错

### 9.4 索引赋值

```凡
变量 数字 = [10, 20, 30]
数字[0] = 99
数字[1] 为 88
```

- 越界赋值**报错**，不自动扩容
- **常量数组只锁定变量绑定，元素可以修改**：

```凡
常量 数字 = [1, 2, 3]
数字[0] = 9      注释 合法
数字 = [4, 5]    注释 错误：常量不可再赋值
```

### 9.5 引用语义

数组赋值传递**引用**，不做值拷贝：

```凡
变量 甲 = [1, 2, 3]
变量 乙 = 甲
乙[0] = 99
甲[0]            注释 99
```

### 9.6 运算支持

| 运算 | 支持 | 说明 |
| --- | --- | --- |
| `+` / `加` | 支持 | 数组拼接，返回**新数组**，不改动原数组 |
| `-` `*` `/` `%` | 不支持 | 报错 |
| `==` / `等于` | 支持 | **深度比较**：长度与每个元素都相等才为真 |
| `!=` / `不等于` | 支持 | `==` 取反 |
| `<` `<=` `>` `>=` | 不支持 | 报错「数组不支持大小比较」 |
| `且` `或` `非` | 不支持 | 非布尔报错 |

```凡
[1, 2] 加 [3]        注释 [1, 2, 3]
[1, 2] 等于 [1, 2]   注释 真
```

### 9.7 函数调用语法（内建函数用）

```凡
名称(参数1, 参数2)
```

- 本轮用于调用内建函数
- 参数以 `,` 分隔，允许尾随逗号，允许跨行
- 说明：此调用形式为内建函数而设，后续设计自定义函数时可能调整

### 9.8 内建函数（本轮）

| 函数 | 说明 | 示例 |
| --- | --- | --- |
| `长度(数组/字典/字符串)` | 元素/键值对/字符个数 | `长度([1,2,3])` → `3` |
| `追加(数组, 值…)` | 返回**新数组**，不改原数组 | `追加([1,2], 3)` → `[1,2,3]` |
| `打印(值…)` | 输出到标准输出，多参数以空格连接并换行 | `打印([1,2,3])` |

### 9.9 打印格式

数组以 `[元素, 元素]` 形式输出，字符串元素**不带引号**：

```凡
打印([1, "二", 真])    注释 输出 [1, 二, 真]
```

### 9.10 字典

键值对集合，字面量用 `{键: 值, ...}`，允许尾随逗号与跨行；键支持整数/小数/字符串/布尔，同一键后写覆盖先写，键按插入顺序保存。

```凡
变量 分数 = {
    "张三": 90,
    "李四": 85,
}
分数["王五"] = 77        注释 新增或覆盖
打印(分数["张三"])       注释 90
打印(长度(分数))         注释 3
打印(分数 的 键)         注释 [张三, 李四, 王五]
打印(分数 的 值)         注释 [90, 85, 77]
打印(分数["不存在"])     注释 空（键不存在返回 空）

遍历 分数 中的 键 值
    打印(键, "->", 值)
结束
```

- 下标读写：`d[键]`；读取不存在的键返回 `空`，写入会新增或覆盖。
- 类型标注：`变量 字典 d`。
- 成员：`长度`、`键`（返回数组）、`值`（返回数组）。
- 遍历：一个变量遍历值；两个变量为 `遍历 d 中的 键 值`，依次得到键和值。
- 比较：`等于`/`不等于` 做深度比较；不支持大小比较与算术。
- 数组/字典等复合类型不能作为键。

## 十、循环语句

`循环` 一词作为**块开始标记**（相当于条件语句里的 `那么`）。将来的遍历语句使用 `遍历` 开头，与本节的循环互不冲突。

### 10.1 条件循环 · 先判断（当 … 循环 … 结束）

```凡
变量 计数 = 0
当 计数 小于 10 循环
    计数 = 计数 加 1
结束
```

规则：
1. 形态固定为 `当 条件 循环` … `结束`。
2. `循环` 必须写出，作为条件表达式的终止标记。
3. 条件在**每轮执行前**求值，为假则退出；条件初次即为假时块体执行 0 次。
4. 条件**必须是布尔**，否则报错。
5. `结束` 必须写出。

### 10.2 条件循环 · 后判断（重复 … 直到 … 结束）

```凡
变量 计数 = 0
重复
    计数 = 计数 加 1
直到 计数 等于 10 结束
```

`直到` 与 `结束` 也可以分行写：

```凡
重复
    计数 = 计数 加 1
直到 计数 等于 10
结束
```

规则：
1. 形态固定为 `重复` … `直到 条件` `结束`。
2. `重复` 后直接进入块体，不带条件。
3. `直到 条件` 是**停止条件**：每轮执行后求值，为**真**则退出循环。
4. 块体**至少执行一次**。
5. 条件**必须是布尔**，否则报错。
6. `结束` 必须写出，可与 `直到 条件` 同行或另起一行。

### 10.3 计数循环（重复 N 次 … 结束）

```凡
重复 3 次
    打印("你好")
结束
```

规则：
1. 形态固定为 `重复 次数表达式 次` … `结束`。
2. 次数可以是任意表达式：字面量、变量、函数调用、算术表达式。

```凡
重复 3 次
重复 甲 次
重复 长度(名单) 次
重复 甲 加 2 次
```

3. 次数求值后**必须是整数**，小数等其他类型报错「次数必须是整数」。
4. 次数为 **0 或负数时执行 0 次**，不报错。
5. 次数在**循环开始前求值一次**（快照）；循环过程中修改次数变量不影响剩余轮数。
6. 块内**没有轮次变量**，需要计数请自行用变量累加。
7. 支持 `跳出` / `继续`；`继续` 跳到下一轮，仍消耗一次计数。
8. `结束` 必须写出。

与 `重复 … 直到 … 结束` 的区分方式：

- `重复` 后**紧跟换行** → 后判断风格（`直到`）
- `重复` 后**跟表达式 + `次`** → 计数风格

计数风格的块体内不允许出现 `直到`，否则报错。

### 10.4 遍历循环（遍历 集合 中的 变量 [变量] … 结束）

```凡
变量 人员列表 = ["小明", "小红", "小刚"]
遍历 人员列表 中的 人
    打印(人)
结束
```

带序号（序号可省略，**元素在前、序号在后**）：

```凡
遍历 人员列表 中的 人 序号
    打印(序号, 人)
结束
```

规则：
1. 形态固定为 `遍历 集合 中的 变量 [变量]` … `结束`。
2. `中的` 是关键字，分隔集合表达式与迭代变量。
3. 变量名位置必须是标识符；第二个变量名可省略，给出时也必须是标识符。
4. 数组与字符串：第一个变量是元素，第二个变量是从 `0` 开始的序号。
5. 字典：一个变量时得到值；两个变量时依次得到键和值。
6. 可遍历类型：**数组**、**字符串**（逐字符，每轮得到一个单字符字符串）、**字典**。其他类型报错「XXX 不可遍历」。
7. 遍历空集合执行 0 次。
8. 开始前对集合做**长度快照**：遍历过程中追加/删除元素不改变本次迭代轮数；但若元素被修改，读到的是最新值。
9. 迭代变量自动声明在循环块作用域内，每轮重新绑定，出循环即消失；可遮蔽外层同名变量。
10. 支持 `跳出` / `继续`。
11. 集合为复杂表达式时建议用括号：`遍历 (甲 加 乙) 中的 项`。简单变量、下标、函数调用可直接书写。
12. `结束` 必须写出。

```凡
遍历 "你好世界" 中的 字
    打印(字)
结束
```

### 10.5 跳出与继续

```凡
跳出      注释 立即结束整个循环
继续      注释 跳过本轮剩余语句，进入下一轮
```

规则：
1. 只能出现在循环体内，否则报错「跳出 只能用于循环内」/「继续 只能用于循环内」。
2. 嵌套循环中作用于**最内层**循环。
3. 不支持带标签跳转。
4. 在 `重复 … 直到` 中使用 `继续` 时，仍会执行本轮的 `直到` 条件判断。

```凡
变量 甲 = 0
当 真 循环
    甲 = 甲 加 1
    如果 甲 等于 3 那么
        继续
    结束
    如果 甲 大于 5 那么
        跳出
    结束
结束
```

### 10.6 作用域与返回值

1. 循环体**每轮新建作用域**：块内声明的变量每轮独立，出循环即消失。
2. 循环体内可读写外层已声明的变量。
3. 循环语句本身返回 `空`。

### 10.7 非法示例

```凡
当 计数 小于 10
    计数 = 计数 加 1
结束
注释 错误：缺少 循环

当 1 循环
结束
注释 错误：条件必须是布尔

重复
    计数 = 计数 加 1
结束
注释 错误：缺少 直到 条件

重复
    计数 = 计数 加 1
直到 计数 等于 10
注释 错误：缺少 结束

跳出
注释 错误：跳出 只能用于循环内

重复 2.5 次
结束
注释 错误：次数必须是整数

重复 3 次
    甲 = 1
注释 错误：缺少 结束
```

## 十一、函数与类

### 11.1 函数定义

```凡
定义 函数 求和(甲 整数，乙 整数) -> 整数
    返回 甲 加 乙
结束

函数 问候(名字 字符串, 称呼 字符串 = "你好")
    打印(称呼, "，", 名字)
结束
```

- `定义` 可省略；函数定义语法为 `[定义] 函数 名(参数列表) [-> 返回类型]`。
- 参数类型放在参数名后面，可用 `,`、`，`、`、` 分隔；参数类型可省略（动态类型）。
- 默认参数用 `名字 = 默认值`，默认值在调用时计算；默认参数必须放在普通参数后面。
- 可变参数必须是最后一个参数，写法为 `名字 ...类型` 或 `名字 ...`；函数体内得到数组。
- 括号同时支持半角 `()` 和全角 `（）`。
- 返回类型用 `->`（或全角 `→`）声明；单个类型 `-> 整数`，多个类型 `-> (整数，错误)`；声明后运行时强制检查。
- 函数体换行开始，`结束` 收尾。
- `返回 值` 返回；无 `返回` 或无值则返回 `空`；末尾表达式自动返回。
- `返回 值1、值2` 返回多个值；多返回值必须用多目标赋值接收：`变量 a、b = f()`。
- 多返回值作为函数实参时会自动展开：`g(f())` 等价于把 f 的每个返回值分别传给 g。
- 多目标赋值 `a、b = f()` 要求左侧变量均已声明；左侧数量必须与返回值数量一致。
- 匿名函数：`变量 平方 = 函数(数 整数) -> 整数 返回 数 乘 数 结束`。
- 函数是一等值，支持闭包、递归、作为参数传递。
- 关键字不能用作函数名或参数名（如 `加`、`数组`）。

### 11.2 调用语法（括号可选，歧义时使用）

| 写法 | 等价 |
| --- | --- |
| `打印 "张三"` | `打印("张三")` |
| `名单 追加 "张三"` | `追加(名单, "张三")` |
| `名单 的 长度` | `长度(名单)` |

- 无括号时参数吃到行尾，多参数必须用 `,`。
- 函数或方法没有参数时，调用括号可以省略：`名`、`对象 的 方法`。
- 字段与无参方法同名时，优先访问字段。
- `IDENT IDENT ...` 识别为接收者调用：第二个标识符是方法名，第一个标识符作为首参。
- `obj 的 member` / `obj.member` 等价，可用于字段、方法和数组成员。

### 11.3 模型定义

模型参考 Go：模型内只定义字段，方法在模型外部定义。

```凡
定义 模型 矩形
    变量 整数 宽
    变量 整数 高
结束

定义 矩形 的 方法 初始化(宽 整数，高 整数)
    自己.宽 = 宽
    自己.高 = 高
结束

定义 矩形 的 方法 面积() -> 整数
    返回 自己.宽 乘 自己.高
结束
```

- 使用 `模型` 关键字（`类` 也兼容保留），`定义` 可省略。
- 字段用 `变量 [类型] 名` 声明，类型与变量声明一致；默认 `空`。
- 方法在模型外定义：`定义 模型名 的 方法 方法名(参数列表) [-> 返回类型]`。
- 方法体内用 `自己` 访问当前实例的字段和其它方法，无需把接收者写进参数列表。
- 方法可在任意位置扩展；后定义的同名方法会覆盖先定义的方法。
- 方法支持参数类型与返回类型。
- `初始化` 是可选构造方法，`模型名(参数)` 实例化时自动调用。
- 字段/方法通过 `.` 或 `的` 访问：`自己.宽`、`r 的 面积()`。
- 不能动态添加未声明字段。
- 模型体内只能包含字段与嵌入，不再允许写方法。

### 11.4 组合（嵌入）

```凡
模型 学生
    嵌入 人
    变量 学号
结束
```

- 使用 `嵌入 类型名` 复用字段和方法，不支持类继承。
- 嵌入成员会被提升；同名冲突时必须显式通过嵌入类型访问。

### 11.5 鸭子类型

不需要接口；只要对象有对应方法即可调用：

```凡
函数 让它说(动物)
    动物.说话()
结束
```

### 11.6 错误处理（Go 风格）

错误是值，约定函数返回值的最后一个为 `错误` 类型；无错误时返回 `空`。

```凡
函数 除法(a 整数，b 整数) -> (整数，错误)
    如果 b 等于 0 那么
        返回 0、错误("除数不能为零")
    结束
    返回 a / b、空
结束

变量 商、err = 除法(10, 0)
如果 err 不等于 空 那么
    打印("出错：", err.消息)
结束
```

- `错误("消息")` 构造错误值；`错误.消息` 读取消息字符串。
- `错误` 可作为类型标注：`变量 e 错误`、函数返回 `-> 错误` 或 `-> (整数，错误)`。
- **`检查 调用`**：若调用的最后一个返回值是错误，立即从当前函数返回（前置返回值用该类型零值填充）；否则剥掉错误位，把前面的值作为结果。
- 函数最后一个返回类型必须是 `错误`，`检查` 才会生效；否则错误会向上抛成运行时异常。
- **`尝试 … 捕获 [名字] … 结束`**：捕获代码块中由 `检查` 传播出来的错误，可在捕获块中访问错误对象。

```凡
尝试
    变量 r = 检查 除法(10, 0)
捕获 e
    打印("捕获：", e.消息)
结束
```

## 十二、模块系统

### 12.1 导出

模块是一个 `.凡` 文件。文件中用 `导出` 标记对外部可见的名字；未导出的名字只能在本文件内使用。

```凡
导出 变量 版本 = "1.0"

导出 函数 加倍(n 整数) -> 整数
    返回 n 乘 2
结束

函数 内部辅助()
    返回 "私有"
结束
```

- `导出 变量/常量 名 = 值`
- `导出 函数 名(...) ... 结束`
- `导出 模型 名 ... 结束`

### 12.2 导入

```凡
导入 "路径/模块名"
打印(模块名.加倍(21))

导入 "路径/模块名" 作为 m
打印(m.加倍(5))
```

- 导入路径相对于**当前运行脚本所在目录**解析，也可写 `.凡` 后缀。
- 不写 `作为` 时，模块名取路径最后一段（去掉后缀）。
- 通过 `模块名.导出成员` 访问导出的变量、函数和模型；可直接调用 `m.函数()`、用 `m.模型()` 实例化。
- 未导出成员在模块外不可见。
- 同一模块重复导入只执行一次并缓存；检测到循环导入会报错。
- 找不到模块会报「找不到模块：…」。

## 十三、标签系统

标签使用 `@模型名` 声明，用于给模型、函数或方法附加真实的标签模型实例。标签不是注解；没有对应处理器时不会改变执行行为。

```凡
模型 标记
    变量 说明
结束

@标记(说明 = "示例")
定义 函数 测试()
    返回 42
结束
```

- 标签名必须是已定义模型。
- 未命名参数最多一个，写入标签模型的 `值` 字段。
- 命名参数写入同名字段。
- 创建标签实例时不调用模型的 `初始化` 方法。
- 标准接口定义在 `internal/tagsys`。
- 标签处理器可以通过标签上下文替换目标当前实现。
- 目标对象本身不会被替换，参数契约和返回类型契约仍然生效。

```凡
@内建("打印")
定义 函数 输出(内容 ...)
    返回 空
结束
```

`@内建` 会在解释阶段查找 Go 内建函数注册表；找不到时立即报错。也可以通过 `注册标签处理` 使用凡语言函数注册标签实现。
